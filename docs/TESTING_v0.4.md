# 院內測試 v0.4.0(2026-09)

沙箱已通過:單元與情境 32/32、端對端 15/15(真 Chromium 載入外掛,偽造健保雲端與 NIIS)。以下只能在院內驗。

## 準備
- 門診電腦(已裝讀卡機、ServiSign、Chrome ≥ 116,能開健保雲端與 NIIS)
- 醫事人員卡;病患健保卡 3–5 位,至少 1 位有肺鏈接種史(PCV13/PPV23)、1 位 65 歲以上從未接種

## 步驟(每步記錄結果)
1. 插卡登入健保雲端,進任一頁 → 右下「疫苗檢核」鈕。沒出現:F12 Console 找 `[疫苗檢核]`。
2. 按鈕 → 面板:姓名、年齡、性別正確;來源列 6 項狀態。任何「讀取失敗」→ 截圖 Console 錯誤。
3. 看肺鏈與流感結論;展開「判定依據」,理由讀起來對不對。
4. 按「查接種史(NIIS 需過卡)」→ 開 NIIS 分頁。**第一次請記下 NIIS 查詢頁真正的網址**,填進設定頁「NIIS 查詢頁網址」。
5. 在 NIIS 照常過卡查詢 → 頁面底部出現「已擷取 N 筆」。出現「找不到身分證欄位」→ 回報。
6. 回健保雲端:接種史變「已取得」,肺鏈結論依接種史更新。面板若出現「NIIS 有未對應的疫苗」→ 把名稱抄給我。
7. 有需確認項時,勾一個,看結論是否改變;有「依病歷判定」時按「取消」看是否回到需確認。
8. 換下一位病患插卡 → 面板自動關閉;再按鈕是新病患。
9. (選)F12 在 NIIS 頁 Console 執行 `document.querySelector('#btn_Query').click()`,看是否跳讀卡/PIN。可行 → 設定頁開「自動按查詢」。
10. 有疑問的病患按「匯出診斷檔」。檔案已排除姓名與身分證,但仍是病歷資料,傳給我前請去識別。

## 最想知道的四件事
- 肺鏈接種史的判定是否與你臨床判斷一致(找 1–2 位有接種史的病患)
- NIIS 查詢頁網址與身分證欄位是否如預期
- 縣市自購疫苗在 NIIS「批號類型」寫什麼
- 健保雲端 API 是否全部讀得到(特別是 IMUE0190 特殊給付)

沙箱已通過:單元與情境 80/80、端對端 33/33(真 Chromium,本機 HTTPS 代理偽造健保雲端與 NIIS)。

- W1. 設定頁(在標題列圖示按右鍵 →「選項」)確認兩個網址;把「健保雲端入口網址」改成插卡後網址列顯示的實際路徑。
- W2. 關掉所有健保雲端/NIIS 分頁 → 插卡 → 按圖示 → 兩個分頁開啟(NIIS 在健保雲端右側、背景),健保雲端面板自動出現。
- W3. 分頁開著,換插下一位病患的卡 → 按圖示 → 外掛自動按「請換卡再按我」,30 秒內換成新病患的結果;NIIS 分頁導回查詢頁。
- W4. 在 NIIS 手動按「讀取健保卡及醫事人員卡」→ 確認有沒有要求 PIN → 結果自動併回健保雲端面板。
- W5. 設定頁開啟「自動按 NIIS 讀取健保卡及醫事人員卡」(autoClickNiis)→ 重做 W2 → NIIS 自動查詢,結果自動併回。
- W6. 不插健保卡直接按圖示(autoClickNiis 開啟)→ 應顯示「NIIS 未讀到健保卡」,肺鏈不可出現「可打」或「建議接種」。
- W7. 每一步回報:院區/電腦、外掛版號、步驟編號、截圖、F12 Console 中 `[疫苗檢核]` 開頭的訊息。

注意:
- 讀卡失敗時 NIIS 頁面會自己跳 alert 並卡住頁面;外掛不重試、不關 alert,請手動按確定。
- 換卡代按若有副作用(例如跳出錯誤、登出),設定頁關掉「自動按健保雲端『請換卡再按我』」並回報。
- 上方舊步驟 4、9 已由 W2、W5 取代(NIIS 查詢頁 = 根網址,已確認)。

## v0.4.10 健保雲端自動登入 + 面板排序 院內測試

沙箱已通過:單元與情境 94/94、端對端 43/43。

- L1. 關掉所有健保雲端分頁 → 插卡 → 按圖示 → 不需手動按「實體健保卡」,直接進病人資訊頁,面板自動開。(網址應先是 `/imu/IMUE1000/?type=icc`,登入後轉到主畫面)
- L2. 登入後換卡 → 按圖示 → 走「請換卡再按我」,不應重新整頁登入(網址不應出現 `?type=icc`)。
- L3. 面板順序:可接種 → 待確認 → 不符合,各組有小標題與筆數;展開判定依據,「符合」在前、「不符」在後。
- 若 L1 停在登入頁:15 秒後外掛會代按「實體健保卡」一次(Console 有「代按『實體健保卡』登入」);再 30 秒仍未登入會提示「健保雲端登入未完成,請確認醫事人員卡與健保卡已插入」。請回報是哪一種情況(代表 `type=icc` 可能已失效)。
- 設定頁「健保雲端入口網址」若仍是舊值 `/imu/IMUE1000/IMUE2000`,升級後會自動改成 `/imu/IMUE1000/?type=icc`;W1 若已改成自訂路徑,則保留不動(想用自動登入請手動改回)。
