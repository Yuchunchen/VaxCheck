# 疫苗檢核程式 — 專案憲章(charter)v0.1

日期:2026-09-16  狀態:待 YC 確認  取代:01_ARCHITECTURE §7 範圍護欄

## 1. 一句話

門診插健保卡 → 一鍵 → 這位病患「現在能公費打哪些疫苗、不能的原因、補什麼條件就能打」。
規則自動跟著疾管署與縣市公告更新;人只在高風險差異出現時介入。

## 2. 目標與非目標

目標(做)
- 判定:公費資格、劑次與最早可打日、不符原因、需醫師確認的條件。原則:預設不可(default-deny),unknown 永遠不放行;能自動判「可打」就不再問;判不出時只問決定性的條件;病歷有證據的條件先預勾(10)。
- 規則:中央疾管署通則 + 縣市擴大對象,以疊加(overlay)方式維護;先做花蓮、台東。
- 規則供應鏈(rule supply chain):偵測 CDC 頁面變動 → 自動產生規則 → 自動閘門 → 自動上線;高風險差異才人核。
- 可稽核:每次判定帶規則版本、管轄、來源快照雜湊(hash)。
- 他院易裝:商店連結安裝、選項頁設管轄、縣市規則可加;另有獨立 HTML 手動模式供示範與備援。

非目標(擋)
- 重做健保雲端任何頁籤的瀏覽器功能、慢性病管理提醒、自費疫苗推薦、用藥/檢驗儀表板、接大型語言模型(LLM)產生病患解釋。
- 執行期讀 Notion、每日產生邏輯物件當執行物(09-15 決策維持)。
- 這一輪不做 HIS 接口、VPN 資料通道、院內伺服器(選項 C);只留 adapter 空位。
- 不做全台縣市規則內容;只做 schema 與目錄慣例,讓他院可加。

## 5. 資料來源與接口

現行(自動)
- 健保雲端 JWT:身分證(只用雜湊)、生日、性別。
- IMUE0008 用藥(ICD、ATC)、IMUE0040 過敏(僅顯示)、IMUE0060 檢驗、IMUE0190 特殊給付(lftp)、IMUE2000 病人資訊摘要旗標。
- NIIS 院所版:接種史(需醫事人員卡,半自動)。

現行(人工)
- 面板勾選:原住民、孕婦、機構住民、IPD 高風險、洗腎、聲明書、嚴重過敏、急性發燒;新增:設籍/居住縣市。

預留(只留空位,回 status: unavailable)
- `adapters/his/`:病患戶籍或居住地址、院內診斷。
- `adapters/niis-api/`:若日後 NIIS 有資料交換介面(VPN 定義待 YC 補)。
- 特材紀錄(10.1)端點。

## 6. 疫苗清單與狀態

- 肺炎鏈球菌 PCV20/PCV21:正式(Policy 2026-08-10)。NIIS 肺鏈名稱對照仍是推測 → 院內驗證。
- 季節性流感:示範。示範的「50–64 歲高風險」與我對現行 CDC 對象(6 個月以上具潛在疾病者)的理解不同;正式轉譯以管線抓到的頁面為準,不採我的記憶。這正是你舉的「25 歲有慢性病可打」的情況。
- COVID-19:尚未寫;由管線第一次跑產出草稿(新疫苗 = 高風險 → 人核)。
- 帶狀皰疹:探勘見 NIIS「帶狀皰疹疫苗/公費」紀錄 → 是否納入待 YC 確認。

B.1 原則(寫進 AUTHORING):每個自動判定的臨床條件都配一個 manual 後備,實作形式為 `manualConditions[].evidence`(10 §2);肺鏈的 IPD 群收斂為 `manual: ipdHighRisk`,流感正式化時比照。

## 7. 人與責任、稽核

- 規則 owner:YC,角色是發起與核准,不直接改 YAML;修改一律透過 Claude(08)。黃金案例只由 YC 發起的 PR 增修,管線不得改。
- 閘門不分作者:管線 LLM、Claude、緊急人工 PR 都過同一套 validate / test / 黃金 / 差異分級;高風險一律 YC 按核准。維護門檻因此不再是 YAML + Git,其他維護者(感控、衛生局窗口)也走同一條路。
- 縣市 overlay:一縣一檔,CODEOWNERS 指定核准者;現階段兩檔由 YC 發起、Claude 維護。
- 稽核軌跡:GitHub PR 歷史 = 核准紀錄;Result 帶 ruleSetVersion、jurisdiction、來源快照雜湊;面板底部顯示。
- 未定:院內是否需要正式核准流程(感控/藥委會)。先標「待補」,不阻塞。

## 8. 風險登錄

- R1 LLM 誤讀規則 → 閘門一(測試/黃金)+ 閘門二(差異分級)+ 影子模式(shadow mode)先跑。
- R2 GitHub 供應鏈 → 分支保護、必要審核、sha256 校驗;簽章為選配(待 YC 決定)。
- R3 院內 Chrome 連不到 github.io → 內建後備規則;備案:推檔到 dist 資料夾。待驗。
- R4 工作站管轄設定錯 → 未設定 = 只用中央;面板醒目顯示適用管轄。
- R5 縣市公告來源不穩 → 縣市層先監看提醒,不自動產生(D-08)。
- R6 NIIS 肺鏈名稱未實見 → 院內驗證(未完成承諾)。
- R7 誤判成本不對稱(誤判可公費 → 費用追回;誤判不可 → 漏打)→ 三值邏輯 + 人核紀錄。

## 9. 順序與依賴(建議,可重排)

0. 院內驗證 v0.3.0(02_TESTING §C)。肺鏈 NIIS 名稱是黃金案例的輸入,先做省重工。

2. 黃金案例集:先肺鏈(從 46 個情境測試抽)、再流感/COVID 正式化時補。
3. 外掛執行期抓規則 + sha256 + 離線後備 + 版本釘住;選項頁;手動模式打包(共用建置)。

5. 流感、COVID-19 正式轉譯(管線草稿 + 人核)。
6. 縣市 overlay 花蓮/台東(公告由 YC 提供,Claude 依 08 填寫,不猜)。
